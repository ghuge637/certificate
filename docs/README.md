# Certificate Automation System Documentation

Welcome to the **Certificate Automation System** project documentation.

## Project Overview
The Certificate Automation System is a Spring Boot web application designed to manage, issue, and verify academic and professional certificates for educational institutions and organizations.

## Key Features
- **Dual-Role Portal**: Dedicated login interface for **Students** and **Staff/Administrators**.
- **Student Dashboard**: Request certificates, track issuance status, and download verified digital certificates.
- **Staff Dashboard**: Review certificate requests, approve/reject applications, and issue digital certificates.
- **Verification Portal**: Publicly verify certificate authenticity using unique certificate IDs.
