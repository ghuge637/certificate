# Project Setup & Eclipse Run Guide

## Requirements
- **JDK 17** or higher
- **Eclipse IDE** (Eclipse IDE for Enterprise Java and Web Developers or STS)
- **Maven 3.8+** (Embedded in Eclipse)

## How to Import in Eclipse
1. Open Eclipse $\rightarrow$ **File** $\rightarrow$ **Import...**
2. Choose **Maven $\rightarrow$ Existing Maven Projects**.
3. Select the `e:\environment\certificate` directory.
4. Click **Finish**.

## How to Run in Eclipse
1. Open `src/main/java/com/automation/system/certificate/CertificateApplication.java`.
2. Right-click inside the editor window.
3. Select **Run As $\rightarrow$ Java Application** (or **Run As $\rightarrow$ Spring Boot App**).
4. Access `http://localhost:8080` in your web browser.
